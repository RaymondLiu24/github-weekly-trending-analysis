## 個人精選

### [akitaonrails/ai-memory](https://github.com/akitaonrails/ai-memory) 🧠（本週排名：12）

- **它在做什麼：** 用 Rust 打造的跨 agent 長期記憶系統，透過生命週期 hooks 擷取 Claude Code、Codex、Cursor、Gemini CLI 等 9 種以上 coding agent 的操作紀錄，彙整成一份純 Markdown、git-backed 的共享 wiki；換 agent 或換終端機時，新 session 會自動拿到「交接摘要」，不必重新解釋架構、已試過的方案與待解問題。
- **跟我的方向有什麼關係：** 「跨 agent 共享記憶」正是個人 AI 助理最核心的痛點——如何讓 Claude Code、Codex 等不同工具共用同一份長期記憶，而不是各自為政、每次都要重新自我介紹。它刻意不用向量資料庫，改用「grep 得到、可在 Obsidian 打開」的純文字 wiki，是 PKM 與 agent memory 交界處值得參考的設計案例。
- **值得注意的技術選擇：** 用輕量 lifecycle hooks 做「零摩擦擷取」，而非要求 agent 主動呼叫 write_note；記憶儲存採純 Markdown + git 而非向量 DB，換取可讀性、可版本控制與零維運成本。這種「先求可攜與透明，再談語意搜尋」的取捨，對設計個人記憶系統是很實際的參考點。

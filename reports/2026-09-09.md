## 個人精選

### [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) 🧠（本週排名：13）

- **它在做什麼：** Nous Research 開源的「自我進化」AI agent，內建持續學習迴圈——從實際任務中自動萃取並改進 skills、用 FTS5 全文檢索與 LLM 摘要搜尋自己過去的對話紀錄，並透過 Honcho dialectic 使用者建模技術，跨 session 逐步建構「你是誰」的深度模型；可透過 Telegram、Discord、Slack、WhatsApp、Signal 等多種管道與使用者互動，並能在 5 美元 VPS 到 GPU 叢集、Serverless（Daytona／Modal）等環境上運行。
- **跟我的方向有什麼關係：** 「agent 主動累積並深化對使用者的理解，而非每次對話從零開始」正是個人 AI 助理的核心命題；它把記憶拆成「curated memory + periodic nudges」與「session 搜尋」兩層，跟個人 AI 助理 super project 想解決的「長期記憶 vs. 即時檢索」分工問題高度呼應，也示範了「助理無所不在」（多平台 gateway、跨裝置延續對話）而非侷限單一介面的產品思路。
- **值得注意的技術選擇：** 用 Honcho 做「dialectic user modeling」而非單純向量儲存，強調對使用者的理解是透過對話持續推理、修正得出，而非一次性 embedding；同時相容 agentskills.io 開放標準，讓 skills 可跨 agent 生態系移植，是「記憶」與「能力」兩條主線分別走向標準化的具體案例。
